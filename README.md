# 타이니 캣워 — 웹 빌드

브라우저에서 바로 플레이: **https://bbangrae.github.io/catwar-play/**

이 저장소는 Unity WebGL **빌드 결과물만** 담습니다. 게임 소스는 별도 비공개 저장소에 있습니다.

- 세로 화면(9:16) 기준으로 만들어졌습니다 — 모바일에 맞습니다
- 첫 로딩에 시간이 걸립니다 (wasm 다운로드 + 컴파일)
- 소리는 화면을 한 번 터치/클릭한 뒤에 나옵니다 (브라우저 자동재생 정책)
